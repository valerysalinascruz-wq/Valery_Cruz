# Analizador de Ventas por Producto

Programa en Python que procesa registros de ventas desde un archivo CSV o desde la entrada estándar (`stdin`), calcula estadísticas por producto y genera un reporte ordenado según el ingreso total obtenido.

El programa valida datos incorrectos, ignora filas inválidas y calcula automáticamente:

- Unidades vendidas
- Ingreso total
- Precio promedio por producto

---

# Características

- Lee datos desde archivos CSV o consola.
- Agrupa información por producto.
- Calcula ingresos automáticamente.
- Calcula precio promedio de venta.
- Ordena productos por mayor ingreso total.
- Ignora líneas inválidas o incompletas.
- Genera salida en formato CSV.

---

# Requisitos

- Python 3.8 o superior
