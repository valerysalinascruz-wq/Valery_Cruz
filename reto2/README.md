# Clasificador de Temperaturas

Programa en Python que procesa datos climáticos desde la entrada estándar (`stdin`), convierte temperaturas de Fahrenheit a Celsius y clasifica el clima según la temperatura obtenida.

El programa valida datos incorrectos, ignora líneas inválidas y genera una salida limpia en formato CSV.

---

# Características

- Lee datos desde consola o archivos CSV.
- Convierte temperaturas de Fahrenheit a Celsius.
- Clasifica automáticamente la temperatura.
- Ignora líneas vacías o incorrectas.
- Valida unidades de temperatura (`C` y `F`).
- Genera salida en formato CSV.

---

# Clasificaciones de temperatura

| Rango en Celsius | Clasificación |
|---|---|
| Menor a 0 | Congelante |
| 0 a 15 | Frío |
| 16 a 25 | Templado |
| 26 a 35 | Cálido |
| Mayor a 35 | Extremo |

---

# Requisitos

- Python 3.8 o superior
